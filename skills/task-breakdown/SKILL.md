Break the input into a sequence of practical tasks.

Organize the tasks as a clear delivery narrative with natural progression: first clarify what is uncertain, then prepare what is needed, then execute the main work, then check and finalize.

Shape each task to be small enough for one focused execution pass, large enough to create observable progress, and independently verifiable.

Each task should be clearly connected to the next one and explain why it comes at that point in the sequence.

For every task, include:
- Goal
- Why this comes now
- What must be true before starting
- What “done” means
- How to confirm it worked

Prefer vertical, verifiable progress over grouping tasks by technical layer.
